# Loot Runes

![Loot Runes banner placeholder](https://raw.githubusercontent.com/iamkaf/modresources/refs/heads/main/pages/lootrunes/banner.png)

[![Requires Amber](https://img.shields.io/badge/Requires-Amber-ebb134?style=for-the-badge)](https://modrinth.com/mod/amber) [![Issues](https://img.shields.io/github/issues/iamkaf/mod-issues?style=for-the-badge&color=eeeeee)](https://github.com/iamkaf/mod-issues) [![Discord](https://img.shields.io/discord/1207469438719492176?style=for-the-badge&logo=discord&label=Discord&color=5865F2)](https://discord.gg/HV5WgTksaB)

Loot Runes is a work-in-progress mod where you unlock runes and keep up to three active through a Rune Tablet. Your loadout will change how mobs drop loot and reward different ways of hunting.

**The rune system isn't playable yet.** Current builds still contain the old skeleton-assisted drop mechanic from Extended Golf while the project is being modernized.

Planned runes include extra loot rolls with tougher mobs, trading common drops for rarer ones, kill-streak rewards, alternate biome drops, and bonuses for changing weapons. Runes will be permanent unlocks, so the tablet is where you choose a loadout rather than where you store another inventory full of items.

The current source targets Fabric and NeoForge and requires [Amber](https://modrinth.com/mod/amber).

The mod namespace is `lootrunes`. Existing datapacks need to move from `data/extendedgolf/` to `data/lootrunes/`. There is no stable datapack format for the planned rune system yet.

You can include Loot Runes in modpacks without asking first.
