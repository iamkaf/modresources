A minimal location HUD for Fabric, Forge, and NeoForge.

Requires [Amber](https://modrinth.com/mod/amber) and [Konfig](https://modrinth.com/mod/konfig). Fabric files also
require [Fabric API](https://modrinth.com/mod/fabric-api). Client-side only.

The HUD sits in the top-left corner and shows your coordinates, the direction you're facing, the biome you're in,
and the current day.

### How To Use It

Toggle the HUD with the keybind (default `N`) and copy your coordinates holding shift plus the keybind (default `Shift+N`).

### Configuration

Open Kaf HUD's settings from your loader's mod list. On Fabric, install [Mod Menu](https://modrinth.com/mod/modmenu)
to add the configuration button.

- Turn each line on or off: coordinates, direction, biome, and day counter.
- Show the direction as text or arrows, with a color for each direction.
- Pick the text color for each line.
- Add a background behind the HUD, as one panel or one strip per line, in any color.
